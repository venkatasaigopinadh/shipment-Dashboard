Chocolate Shipments Data Analysis (2023–2025)

🚀 Excited to share my latest Power BI Data Analysis Project – Chocolate Shipments Analysis (2023–2025) 📊🍫
In this project, I worked on analyzing shipment data to identify sales trends, shipment performance, order status insights, and business growth patterns using Power BI.
🔹 Project Overview
The dataset contains shipment records from 2023 to 2025 with details such as: Shipment ID, Product ID, Sales Person ID, Geo/Region ID, Shipment Date, Shipment Amount, Number of Boxes, Order Status
🔹 Key Insights from the Analysis
✅ Total Shipments Analyzed: 25,076+
✅ Total Revenue Generated: 141M+
✅ Total Boxes Shipped: 8.8M+
✅ Order Status Tracking:
Delivered Orders, Shipped Orders, Cancelled Orders, Placed Orders
🔹 Dashboard Features
📈 Line Chart Analysis for Last 13 Months
📊 Revenue Trend Analysis
📦 Shipment Volume Tracking
🌍 Regional Shipment Insights
📅 Time-Based Filtering using Calendar Table
🎯 Interactive Filters & Slicers
🔹 Steps Followed in the Project
1️⃣ Imported Excel shipment dataset into Power BI
2️⃣ Cleaned and transformed data using Power Query
3️⃣ Created relationships between shipment, calendar, and dimension tables
4️⃣ Built DAX measures for:
Total Revenue, Total Shipments, Total Boxes, Order Status Analysis
5️⃣ Designed interactive dashboards and KPIs
6️⃣ Applied date filters to display only the last 13 months of data
7️⃣ Created visualizations such as line charts, KPI cards, and status reports
8️⃣ Generated business insights for shipment performance monitoring
